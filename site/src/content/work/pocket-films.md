## One shared base system across every platform

<p class="cs-sub">A single token foundation powering mobile, web and every level of user.</p>

We built a shared base design system that every surface inherited from: the consumer mobile app, the provider web platform and the system admin. All the tokens were shared, so colour, type, spacing and component decisions were defined once and cascaded everywhere, keeping mobile, web and admin consistent while each adapted to its own context.

## Bringing Pocket Films to life

<p class="cs-sub">Designing the experience across mobile and desktop, for different users.</p>

Pocket Films needed an experience that could serve two very different audiences: production teams sourcing locations, crew and equipment, and service providers looking to be discovered. The challenge was making a complex marketplace feel effortless.

Working closely with the product and engineering teams, Pebble led the UX and UI design from concept through to the shipped mobile app and web platform.

- **User experience:** intuitive workflows for project creation, provider discovery, shortlisting and team collaboration, balancing the needs of both sides of the marketplace.
- **User interface:** a cohesive design system that works across web and iOS, supporting light and dark modes with a modern, clean aesthetic.
- **AI-powered discovery:** the interface for Juno AI, which matches provider profiles to active production needs in context, moving beyond simple keyword search.
- **Provider experience:** the provider-facing tools, including profile management, subscription tier selection and analytics dashboards.
